What the mastering chain does

01

3-band EQ

Low-shelf, mid-peak, high-shelf — real biquad filters. Warmth/Clarity/Air above.

02

Compressor

Linked stereo — one gain per sample-frame from whichever channel is louder. Punch above.

03

Limiter

A true brickwall ceiling — nothing gets past it. Loudness above.

04

Streamed, chunk by chunk

Processes a few seconds at a time so an 8-minute take uses the same memory as a 30-second one.

Why this works this way: nothing here is faked. The beat is real synthesis, your recording is real audio from your real microphone, and the mix/master is a real Larzscript program running on the server, now with a native-C fast path for the heavy per-sample math. Every control above maps directly to a real parameter in that program — turning "Warmth" up really does raise the low-shelf EQ's gain. Full explanations: the docs page.
